# Agent notes: Warped playlist

A React + Vite site where people pick bands from Warped Tour schedules (1995–2018) and get a playlist.

## Song data (read before building anything with songs or playlists)

**Read [`data/README.md`](data/README.md) first.** It documents the song data completely: the file
format, what every field means, how to draw songs and build a playlist (with reference TypeScript), and
how to regenerate or fix the data.

The essentials:

- `src/data/songs/<year>.json` holds, for each band at each tour year, a weighted pool of up to 6 songs,
  keyed by the band's exact `band` string from `src/data/schedules/`. The site reads only these files and
  makes no live API calls.
- Build a playlist by a **weighted random draw without replacement** from a band's `pool`. Use
  `song.artist ?? bandKey` as the artist string.
- A band missing from a year's `bands` has **no song data** for that year (about 40% of band-years). Show
  that state; never guess or borrow another year's pool.
- **Never hand-edit `src/data/songs/*.json`.** They are generated by `scripts/build-song-pools.mjs`. Fix data
  through `data/overrides.json` or `PARAMS`, regenerate, and run `node scripts/validate-song-pools.mjs`.
- The loader, types and draw code do not exist in `src/` yet; `data/README.md` section 2 has the intended
  shape.
- Store only title, artist, year, role and weight: no audio, album art or lyrics. Last.fm data is for
  non-commercial use.

## Schedules

`src/data/schedule.ts` defines the schedule types and lazy loaders (`import.meta.glob`) for
`src/data/schedules/<year>/`. Follow the same lazy pattern for any per-year data.
